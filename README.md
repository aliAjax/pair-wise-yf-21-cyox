# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

手工地毯修复工作室的纹样与修复档案前端：记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色与修复工序，包含纹样局部标记图、修复前后记录、材料色卡、工序进度、按产地筛选的档案列表，以及**补线批次复验闭环**。

## 补线批次复验闭环规则

- **绑定（破损区 → 色卡批次）**：批次必须同时满足「未冻结」「复验已闭环」「余量足够」。任一不满足则整次拒绝，原绑定与工序不变，并记录拒绝台账。
- **占用口径**：未开工/在修区域按预估用量「预留」；完工后按施工实际用量「消耗」；余量 = 总量 − 已耗 − 预留。
- **立即冻结**：在修记录提交完工时，实际用量超过预估（超耗），或色差偏差 ΔE > 2.0，批次立即冻结。
- **冻结级联**：该批次下未开工区域退回待匹配并释放预留与绑定；在修区域维持工序（仍可提交完工留档）；已完工记录永久留档。
- **复验与解冻**：任何批次可发起复验，未结期间暂停绑定。复核人必须不同于报告人且偏差达标（ΔE ≤ 2.0）复验方可通过；冻结批次通过后进入「达标待解冻」，确认解冻后方恢复；正常批次抽检达标即闭环。
- **同步与持久化**：列表、色卡余量、工序进度与产地筛选由同一份状态实时派生；数据存浏览器 `localStorage`（键 `carpet-repair-archive-v1`），刷新保留。无后端、无运行时新增依赖。

## 代码分层

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 批次规则 | `src/lib/rules.ts` | 冻结/复验闭环判定、绑定拒绝原因、ΔE 达标线、解冻前置、复核人校验 |
| 占用校验 | `src/lib/occupancy.ts` | 已耗/预留/余量纯函数聚合、超耗与色差冻结判定 |
| 页面状态 | `src/store.ts` | 唯一事务入口（绑定/开工/完工/冻结级联/复验/复核/解冻/建档），`useSyncExternalStore` 订阅 + localStorage 持久化 |
| 派生展示 | `src/lib/progress.ts` | 工序进度（待匹配/未开工/在修 25%，完工 100%） |
| 页面 | `src/App.tsx`、`src/components/*` | 指标、色卡批次卡、绑定控制台、档案列表、复验台账 |

> 说明：项目未打包 `@types/react`，`src/vendor-types.d.ts` 是仅覆盖所用 React API 的本地类型垫片，未修改依赖。

## 技术栈

React 19 + Vite + TypeScript（无额外运行时依赖）

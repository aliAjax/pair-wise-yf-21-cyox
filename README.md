# hxyfront-62009 地毯修复纹样档案

源提示词编号：2

做一个给手工地毯修复工作室使用的纹样与修复档案前端项目，可以记录地毯产地、年代、结密度、材质、染色类型、破损区域、补线颜色和修复工序。页面需要有纹样局部标记图、修复前后记录、材料色卡、工序进度和按产地筛选的档案列表。

## 技术栈

React + Vite + TypeScript

## 补线批次复验闭环

- **批次规则**（`src/domain/batchRules.ts`）：施工实际用量超耗，或任一在修记录报告色差超限（ΔE > 1.5），批次立即冻结；未开工区域退回待匹配，在修区域保留，已完成记录留档。复验偏差达标且复核人不同于报告人才能解冻。
- **占用校验**（`src/domain/occupancy.ts`）：破损区只能绑定未冻结、复验已结且余量足够的色卡批次；余量 = 入库总量 − 计划占用 − 已消耗。任一校验不通过即整次拒绝，原绑定与工序不变，拒绝原因留痕。
- **页面状态**（`src/App.tsx` + `src/store.ts`）：单一状态树驱动档案列表、色卡余量、工序进度与产地筛选同步；数据存 localStorage，刷新保留。不新增依赖、无后端。
